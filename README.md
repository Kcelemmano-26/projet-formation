# 🚀 Projet Formation - MonApp

**MonApp** est une application Angular moderne développée dans le cadre d'une formation. Elle illustre la création d'un site vitrine responsive avec des composants dynamiques et un design professionnel basé sur Angular Material et Tailwind CSS.

---

## 📦 Informations générales

- **Nom du projet :** projet-formation
- **Framework :** Angular v19
- **Version :** 0.0.0
- **Design system :** Angular Material + Tailwind CSS
- **Langage :** TypeScript

---

## 🎯 Fonctionnalités

- ✅ Navigation responsive (barre de navigation + menu mobile)
- ✅ Slider d’accueil dynamique
- ✅ Section "Fonctionnalités" avec cartes Angular Material
- ✅ Section "Témoignages" clients
- ✅ CTA pour inscription
- ✅ Footer complet avec liens et icônes sociales
- ✅ Authentification basique (Se connecter / S'inscrire)

---

## ⚙️ Scripts npm disponibles

```bash
npm start         # Lance le serveur de développement (ng serve)
npm run build     # Compile l'application pour la production
npm run watch     # Compile en mode watch (développement)
npm test          # Lance les tests unitaires
